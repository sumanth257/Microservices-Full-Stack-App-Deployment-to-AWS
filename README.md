# Microservices-Full-Stack-App-Deployment-to-AWS

📖 Project Overview

This project demonstrates the deployment of a full-stack microservices-based application on AWS, following cloud and DevOps best practices for scalability, security, and maintainability.

🏗 Architecture

Frontend hosted on AWS S3 + CloudFront

Backend microservices built using REST APIs

Services containerized with Docker

Deployed on AWS EC2 / ECS / EKS

Traffic managed using Application Load Balancer / API Gateway

Databases using RDS / DynamoDB

Secure access using IAM and Security Groups

⚙ Key Features

Independent and scalable microservices

Automated CI/CD deployments

High availability and fault tolerance

Secure cloud infrastructure

🚀 **Technologies Used**

AWS (EC2, S3, ALB, IAM, RDS)

Docker

CI/CD

REST APIs

Linux
